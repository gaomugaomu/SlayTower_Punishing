# Skill Creation Framework

Every skill requires:

## Basic Data

-   Skill ID
-   Character ID
-   Orb Color
-   Orb Count
-   Action Cost

## Logic

-   Damage
-   Defense
-   Healing
-   Buff
-   Debuff
-   Orb manipulation

## Presentation

-   Animation
-   VFX
-   Audio

Skills must be implemented through reusable effects.
