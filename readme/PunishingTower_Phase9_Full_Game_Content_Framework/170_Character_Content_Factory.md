# Character Content Factory

Purpose: Create scalable character production.

Workflow:

Character Concept -\> Role Definition -\> Skill Design -\> Data
Configuration -\> Animation Requirement -\> Balance Test -\> Release

Each character contains:

-   Identity
-   Combat Role
-   Orb Interaction
-   Skills
-   Passive
-   Ultimate
-   Leader Skill
-   Required Assets
