# AI Agent Role Definition

The project uses multiple specialized AI agents.

## Main Developer Agent

Coordinates implementation.

## Architect Agent

Maintains architecture consistency.

## Combat Agent

Develops: - Battle flow - Turn system - Signal orb - Effects

## Content Agent

Creates: - Characters - Skills - Enemies - Relics

## Technical Artist Agent

Handles: - Models - Animation - VFX - Timeline

## QA Agent

Creates tests and validates features.
