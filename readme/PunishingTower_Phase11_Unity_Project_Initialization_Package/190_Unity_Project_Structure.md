# Unity Project Structure

Recommended structure:

Assets/Game/

Core/ - Game state - Event system - Utilities

Combat/ - Battle - Turn - Actions - Effects

Construct/ - Characters - Skills - Passives

SignalOrb/ - Orb data - Orb runtime - Matching

Tower/ - Map - Nodes - Rewards

Presentation/ - Animation - VFX - Audio - UI

Data/ - ScriptableObjects
