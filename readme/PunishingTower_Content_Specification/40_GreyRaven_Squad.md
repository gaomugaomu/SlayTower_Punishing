# Grey Raven Squad Design

## Identity

Grey Raven is the first playable squad.

Members: - Lucia - Lee - Liv

The squad represents balanced gameplay.

## Rules

Members are fixed. No character replacement.

Each member has: - Normal Attack - Red Skill - Blue Skill - Yellow
Skill - Ultimate - Passive - Core Passive - Leader Skill

## Design Goal

The player wins through signal allocation, not character swapping.
