# Signal Orb System

Signal Orbs replace cards.

Orb pool works like Slay the Spire deck.

Components: - Draw pile - Hand - Orb queue - Discard pile - Exhaust pile

Limits: - Visible orb queue: 8 - Hand: 16

Colors: - Red - Blue - Yellow - White (special)

All constructs can use all colors.

Color matching improves efficiency.
