# Core Design Pillars

## Pillar 1: Commander Protection

The Commander is the true player entity.

## Pillar 2: Signal Orb Strategy

The main gameplay is arranging and consuming signal orbs.

## Pillar 3: Character Diversity

Characters differ through: - Skills - Passives - Leader Skills -
Ultimate - Orb efficiency

## Pillar 4: Roguelike Growth

No character leveling. Growth comes from: - Orb upgrades - Relics -
Plugins - Temporary events
